# 岱恩英语机测练习系统（非官方）

一个本地优先的英语自适应机测练习工具，按岱恩语培公开介绍的 CEFR 分级与四维能力框架设计：听力、词汇、语法、阅读分别自适应出题，考后生成能力画像、薄弱考点与逐题解析。

> 本项目与岱恩教育、岱恩语培无隶属或合作关系。题库为原创或公开样题改编，不含岱恩官方真题；所有分数与 CEFR 等级均为练习估算，不代表官方测评结果。

## 功能

- **20 分钟自适应定级**：答题过程中持续估算能力值；答得越好，后续题目越难；20 分钟到时自动判级，也可提前结束。
- **1200 道题库**：每部分 300 题，覆盖 A1–C1；听力 300 组材料、每组 1 题，阅读 60 篇短文、每篇 5 题。
- **阅读按 CEFR 能力点设计**：考查主旨、写作目的、推断、词义语境与作者态度，正确答案均为改写表述而非原文照搬。
- **成绩报告**：总分、CEFR 估算、四维雷达、逐题解析、考点正确率、薄弱点建议。
- **错题本**：考试/练习答错自动收集，连续答对 2 次自动标记掌握，支持筛选与重练。
- **分类练习**：按模块、等级、考点选题；练习模式即时反馈，可查看原文与解析。
- **题库浏览**：搜索题干、选项、解析、标签，查看答案与来源，支持题目报错记录。
- **本地数据**：成绩、错题、设置、草稿全部保存在浏览器 localStorage；支持 JSON 导出/导入备份。
- **浏览器 TTS**：听力使用 Web Speech API，无需下载音频文件；考试中每组最多播放 2 次，完成本组后可查看原文。

## 快速开始

环境要求：Node.js 20+（推荐 22/24），npm 10+。

```bash
# 一键启动（首次会自动安装依赖、生成题库）
./start.sh
```

或手动执行：

```bash
npm install
npm run bank:build
npm run dev
```

打开终端提示的地址（默认 `http://localhost:5173`）。

生产构建：

```bash
npm run build
npm run preview
```

## 题库生成

题库不是手工维护的巨大 JSON，而是由 `scripts/content/*.mjs` 中的结构化内容生成：

- **词汇**：100 个词条 × 3 种题型（词义、语境填空、近义替换）= 300 题。
- **语法**：60 个语法点 × 5 个变体 = 300 题。
- **听力**：20 个场景 × 5 个变体 × 3 个考查焦点 = 300 组材料，每组 1 题。
- **阅读**：20 类材料 × 3 个变体 = 60 篇短文，每篇 5 道推断/主旨/目的/词义/态度题 = 300 题。阅读题型参考公开 CEFR 样题的能力点，内容全部重新编写。

修改内容后重新生成并校验：

```bash
npm run bank:build
npm run bank:validate
npm run bank:stats
```

生成器会为每道题写入 `source`（`original` 或 `adapted-public`）、难度、等级、主题、标签与解析。听力/阅读题目通过 `setId` / `passageId` 与材料关联。

为避免“换词不换题”的死板感，生成器还做了多样化处理：词汇每题从 4 组题干模板中选取；语法前缀在 5 种问法中轮换；听力在细节题之外加入主旨、推断与交际目的题，并按变体改写题干；阅读按篇目与变体生成不同问法，真实题干唯一数超过 1000。`npm run bank:validate` 会对多样性做硬性校验。

## 自适应与计分

- 难度 1–5 对应 A1–C1。
- 能力值 `θ` 初始 2.5，范围 `[0.5, 5]`；若上次测过，会参考上次结果设置起始难度。
- 每题按 Rasch 模型计算期望正确率：`p = 1 / (1 + e^(-(θ - b)))`。
- 答对/答错后立即更新：`θ += 0.7 × (结果 - p)`，并限制在范围内。
- 选题时参考近期正确率：连续答对会主动提高目标难度，连续答错则降低目标难度。
- 默认 20 分钟自适应模式不设固定题量；时间到后按全部作答自动估算 CEFR，也可提前点击“结束并判级”。
- CEFR 映射：`θ < 1.5` A1；`< 2.5` A2；`< 3.5` B1；`< 4.5` B2；否则 C1。
- 总分 = 70% 能力值归一化 + 30% 正确率；60 分显示合格，80 分显示优秀。

## 数据与隐私

- 不包含后端、账号或上传逻辑。
- 成绩、错题、设置、考试草稿保存在浏览器 localStorage。
- 最多保留 50 条考试记录。
- 清理浏览器数据前，请在“历史记录”或“设置”中导出 JSON 备份。
- 导入备份会覆盖本机成绩、错题、设置与题目反馈。

## 浏览器与 TTS

- 推荐 Chrome / Edge（桌面版）。
- 听力依赖系统英语音色；若浏览器不支持 Web Speech API，会提示并允许查看原文。
- 可在“设置”中选择英语音色与语速，并试听。
- 考试中每组听力最多播放 2 次；练习模式不限次数。

## 设置

- 主题支持浅色、深色与跟随系统。
- 可选择英语 TTS 音色与语速，并试听。
- 可关闭“自动进入下一部分”：完成每个模块后会暂停，确认后再进入下一部分。
- 清空学习数据会删除成绩、错题、题目反馈和草稿，并结束当前内存中的考试进度。

## 键盘快捷键

考试与练习页面支持：

- `1–4` / `A–D`：选择选项
- `Enter`：下一题 / 下一组
- `F`：标记当前题
- `←` `→`：在题组内切换当前题（考试页）

## 已知限制

- 题库为练习用途生成内容，部分题目为模板化改写，难度与真实考试不完全等价。
- 听力音色与发音质量取决于操作系统/浏览器提供的 TTS 音色。
- CEFR 与分数为模型估算，不适合作为正式语言能力证明。
- 本项目不是岱恩官方产品，不提供官方真题或官方评分。
